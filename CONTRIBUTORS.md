# Tocyn contributors

Tocyn is built and improved by its contributors. Thank you to everyone who has contributed code, documentation, testing, issue reports, design feedback and review effort.

[![Tocyn contributors](https://shieldcn.dev/contributors/nathcymru/Tocyn.svg)](https://github.com/nathcymru/Tocyn/graphs/contributors)

The live GitHub contributor graph is the source of truth for commit-based contribution history. The ShieldCN overview above is generated from that public GitHub data and excludes bot accounts by default.

See [CONTRIBUTING.md](CONTRIBUTING.md) for how to contribute and the [open issues](https://github.com/nathcymru/Tocyn/issues) for current work.

Contributors are recognised for their work; contribution does not create ownership of project infrastructure, tenant data, deployments, trademarks or maintainer credentials.
