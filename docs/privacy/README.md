# Tocyn privacy engineering documentation

These documents support operators/deployers who need to understand Tocyn's technical privacy boundaries. They are engineering documentation, not legal advice and not a representation that a deployment is compliant with the UK GDPR, EU GDPR or any other law.

- [Privacy architecture](privacy-architecture.md) — current status, planned FidesLang metadata and interoperability.
- [GDPR compliance user guide](gdpr-compliance-user-guide.md) — practical inventory, access/erasure workflows and RoPA starter material for deployers.
- [Repository privacy policy](../../PRIVACY_POLICY.md) — only the Tocyn repository/community touchpoints operated by the project.
- [Security policy](../../SECURITY.md) — vulnerability reporting and the security/privacy-metadata boundary.

## Status rule

As of 8 September 2026, current `main` does **not** contain FidesLang declarations. Issues #16 and #17 own that planned implementation. Examples here show how the approved privacy metadata architecture is intended to interoperate once implemented; deployers must not assume those metadata files exist until the implementation issues are completed and released.
