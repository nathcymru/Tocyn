## Objective

Deliver unified, multi-tenant omnichannel ingestion and outbound delivery on Cloudflare, with system-wide cost governance as a prerequisite. No previous third-party-plugin issue existed; this tracker turns the existing milestone's broad direction into distinct specifications without closing unrelated work.

## Sequence and specifications

1. Establish [#50](https://github.com/nathcymru/Tocyn/issues/50) — system-wide Cost & Capacity policy interfaces (v0.1.0 foundation).
2. Complete [#51](https://github.com/nathcymru/Tocyn/issues/51) — durable ingestion, credentials, event/conversation state and delivery contracts.
3. Implement [#52](https://github.com/nathcymru/Tocyn/issues/52) — extend existing enterprise API and reliable signed customer webhooks.
4. Implement [#53](https://github.com/nathcymru/Tocyn/issues/53) — tenant-owned Slack.
5. Implement [#54](https://github.com/nathcymru/Tocyn/issues/54) — tenant-owned Teams.
6. Implement [#55](https://github.com/nathcymru/Tocyn/issues/55) — tenant-owned WhatsApp.
7. Implement [#56](https://github.com/nathcymru/Tocyn/issues/56) — tenant-owned Telegram.

The four vendor adapters can proceed independently once foundation contracts pass; they do not depend on enterprise webhook subscriptions. All six omnichannel specifications use `v0.3.0 - Omnichannel Configuration & Expansion`. The cost issue uses `v0.1.0 - Multi-Tenant Architecture Foundation`. Only the four vendor specifications carry `help wanted`.

## Accepted decisions

- Tenant-owned applications and guided manifests; no central marketplace/OAuth broker in v1.
- Exact raw-byte verification, durable raw-envelope/journal plus Queue pointers, downstream normalization and transactional outbox. No memory-only global DO buffer.
- Conservative default; Aggressive explicit. Owner ceilings constrain tenant settings. Strict reserved admission: replenish or reject on exhausted credits, never optimistic unbudgeted enqueue.
- Provider-specific acknowledgement, measured 50ms warm-path SLO and separate cold-path/CPU/provider-deadline evidence. No guaranteed internet latency or zero Cloudflare bill.
- Bounded 30-second ingress configuration caching and authoritative guarded downstream writes.
- Every configured Slack/Teams root thread creates a ticket; direct chats have one active ticket. Gratitude AI sheds first and defaults to normal new work when unavailable.
- WhatsApp window uses provider occurrence time; UI/API/dispatch enforce it. Templates deferred.
