# Welcome to Tocyn: an open-source helpdesk on Cloudflare

Tocyn means "ticket" in Welsh. I started this project as a fork of Luminatick, with the intention of taking its foundation forward into a richer multi-tenant helpdesk while retaining the MIT licence and crediting the original project.

The direction is a Cloudflare-only application architecture. We are at an early stage: inherited functionality exists, but multi-tenant readiness and new roadmap features need implementation and validation.

I would welcome help with security review, tests, accessibility, documentation and development. You do not have to arrive with a large feature to contribute: a clear bug reproduction or a better setup guide is valuable.

Please introduce yourself and tell us which part interests you. Check the issues before starting substantial work so we can avoid duplication.

Use this space for community discussion. Vulnerabilities should go through SECURITY.md's private reporting route.
