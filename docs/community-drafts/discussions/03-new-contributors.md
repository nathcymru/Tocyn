# New to Tocyn? Find a useful first contribution

You are welcome here whether your strengths are code, documentation, testing, accessibility or security.

Some useful starting points:
- Try the contributor setup and document exactly where you get stuck.
- Reproduce a non-security bug using synthetic data.
- Test a dashboard or portal workflow using only the keyboard.
- Improve an unclear explanation or outdated link.

Choose an existing issue and comment before substantial work. If a task is too large, ask for help breaking it into a smaller contribution. Larger architecture and tenant-isolation work needs coordination and review.

Tell us what interests you and what experience you have, if you wish. There is no need to share personal information. Our contributor guide and code of conduct explain how we work together.
