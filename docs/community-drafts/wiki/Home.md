# Welcome to Tocyn

Tocyn is Welsh for "ticket": an MIT-licensed helpdesk project growing from [Luminatick](https://github.com/05ng/luminatick) into a multi-tenant application on Cloudflare.

We are in early development. The inherited dashboard, portal, widget and backend are the starting point; secure multi-tenancy and the new roadmap are work in progress.
