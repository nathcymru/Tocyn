# Sponsor Tocyn

Tocyn is free and open source under the MIT licence. GitHub Sponsors helps offset project-related costs such as hosting, documentation, test infrastructure and other development services.

[![GitHub Sponsors](https://shieldcn.dev/github/sponsors/nathcymru.svg)](https://github.com/sponsors/nathcymru)

## Monthly tiers

- **$1/month** — supporter
- **$3/month** — contributor to project running costs
- **$5/month** — sustaining supporter

All tiers support the same open-source project. Sponsorship does **not** buy private features, preferential roadmap treatment, a hosted Tocyn service, an SLA, security exceptions or access to contributor/tenant data.
